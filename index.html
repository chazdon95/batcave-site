Batcave

A private, single-user assistant workspace.

Batcave is a personal tool run by one person for their own use. It is not a public service and has no sign-up: the only Google account that can connect to it is its owner's.

What it does with Gmail

When the owner connects their own Gmail account, Batcave can:

  • read the owner's email threads when the owner asks it to, and
  • create draft replies in the owner's Gmail, which the owner reviews and sends themselves.

Batcave has no code that sends email. It never posts, forwards or shares anything on the owner's behalf.
