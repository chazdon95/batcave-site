Privacy policy

Last updated 24 November 2026

Batcave is a private tool used by a single person, its owner. This policy explains what happens to Google user data when the owner connects their own Google account.

What data Batcave accesses

  • Gmail messages and threads (scope gmail.readonly), read only when the owner asks a question about their email.
  • Gmail drafts (scope gmail.compose), used only to create draft replies for the owner to review. Batcave contains no code that sends email.
  • The connected account's email address (scopes openid and email), to show which account is connected.

How it is used

Data is used only to answer the owner's own requests and to prepare drafts for the owner. It is not used for advertising, not sold, not used to build profiles of anyone, and not used to train AI models.

Where it is stored

The access token is stored on the owner's private server in a file readable only by the system administrator account. Email content is fetched when needed and is not copied into a separate database. The server is reachable only over the owner's private network.

Sharing

Google user data is not sold, and not shared with or transferred to anyone for their own use. When the owner asks a question about their email, the relevant text is processed by the AI assistant the owner uses (Anthropic's Claude) only to produce an answer for the owner. The owner's Claude account is set so that conversations are not used to train models.

Limited Use

Batcave's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

The owner can remove Batcave's access at any time at myaccount.google.com/permissions, or with Batcave's own one-step revoke, which also deletes the stored token.

Contact

Questions about this policy: open an issue at github.com/chazdon95/batcave-site.
